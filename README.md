## 💻 Getting Started

To run this React portfolio application locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Mohamed-Fathi-Khalifa/my-portfolio.git
   cd my-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm start
   ```
   Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
